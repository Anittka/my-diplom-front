АГРОМАРКЕТ ТОРШЕНКО — финальная Django-версия для диплома

ВАЖНО:
В этом архиве manage.py лежит сразу в корне проекта.
После распаковки откройте именно эту папку в VS Code.

ЗАПУСК:
py -m venv venv
.\venv\Scripts\Activate.ps1
py -m pip install --upgrade pip
py -m pip install -r requirements.txt
py manage.py migrate
py manage.py createsuperuser
py manage.py seed_demo
py manage.py runserver

Сайт:
http://127.0.0.1:8000/

Админка:
http://127.0.0.1:8000/admin/

Статистика и диаграммы:
http://127.0.0.1:8000/admin/site-statistics/

ЧТО УПРАВЛЯЕТСЯ ЧЕРЕЗ АДМИНКУ:
1. Категории товаров.
2. Товары: название, артикул, описание, категория, наличие, цена/пометка, показ на главной, активность.
3. Фото товаров.
4. Статьи и полезные материалы.
5. Заявки: просмотр, статусы, фильтры, поиск.
6. Настройки сайта:
   - название компании;
   - подзаголовок;
   - телефоны;
   - email;
   - адреса;
   - режим работы;
   - ссылки WhatsApp/Telegram/VK;
   - реквизиты;
   - тексты главной страницы;
   - тексты страниц «О компании», «Контакты», «Доставка», «Полезные советы»;
   - фото склада/компании.

ВЫГРУЗКИ:
В админке у товаров, статей и заявок есть действия:
- выгрузить в Excel;
- выгрузить в HTML.

POSTGRESQL:
По умолчанию проект запускается на SQLite, чтобы сразу работать без OpenServer.
Для PostgreSQL:
1. Создайте базу agromarket_db.
2. Скопируйте .env.example в .env.
3. Заполните DB_ENGINE=postgresql и параметры подключения.
4. Выполните py manage.py migrate.
