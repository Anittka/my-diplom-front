1. Общие положения

Настоящая политика конфиденциальности определяет порядок обработки и защиты персональных данных, получаемых от пользователей сайта.

Использование сайта и отправка обращения через формы обратной связи означает согласие пользователя с условиями настоящего документа.

2. Перечень обрабатываемых данных

При использовании сайта могут обрабатываться следующие данные:

  • имя пользователя;
  • номер телефона;
  • адрес электронной почты при его указании;
  • содержание сообщения, заявки или комментария;
  • файл или изображение, если пользователь добровольно прикрепляет его к заявке;
  • иные сведения, добровольно переданные пользователем.

3. Цели обработки персональных данных

Персональные данные используются для следующих целей:

  • обработка входящих обращений и обратная связь с пользователем;
  • подбор товара, консультация и уточнение информации по заявке;
  • информирование о наличии, сроках поставки, порядке получения и оплате;
  • исполнение обязательств, возникающих из обращения пользователя;
  • улучшение качества обработки заявок и клиентского сервиса.

4. Условия и порядок обработки

Обработка персональных данных осуществляется законно и добросовестно, только в объёме, необходимом для достижения заявленных целей.

Персональные данные предоставляются пользователем добровольно. Оператор принимает необходимые организационные и технические меры для их защиты.

5. Передача третьим лицам

Персональные данные не передаются третьим лицам, за исключением случаев, предусмотренных законодательством Российской Федерации, либо когда такая передача необходима для исполнения обращения пользователя.

Например, отдельные данные могут потребоваться для согласования доставки, оформления документов или связи с пользователем по его заявке.

6. Хранение и защита данных

Срок хранения персональных данных определяется целями обработки, требованиями законодательства и необходимостью работы с обращением пользователя.

Компания принимает разумные меры для защиты данных от неправомерного доступа, изменения, раскрытия или уничтожения.

7. Права пользователя

Пользователь имеет право:

  • получать сведения об обработке своих персональных данных;
  • требовать уточнения, ограничения обработки или удаления данных;
  • отозвать согласие на обработку персональных данных;
  • обратиться по контактам сайта для разъяснения вопросов, связанных с обработкой данных.

8. Использование файлов cookie

Сайт может использовать технические cookie-файлы, необходимые для корректной работы страниц, форм и сервисных сценариев.

Такие файлы не используются для целей, не связанных с функционированием сайта, если иное отдельно не указано пользователю.

9. Формы обратной связи

При отправке формы обратной связи пользователь самостоятельно вводит контактные данные и текст обращения. Эти сведения используются для связи с пользователем и обработки его запроса.

Если пользователь прикрепляет файл, изображение или фото детали, такой материал используется только для уточнения запроса, подбора позиции или консультации.

10. Изменение политики

Администрация сайта вправе актуализировать настоящую политику. Действующая редакция всегда публикуется на этой странице.
