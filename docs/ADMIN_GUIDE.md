# Руководство администратора

Админ-панель оставлена компактной для сайта-визитки. Основные рабочие разделы:

1. **Заявки** — обработка обращений, статусы, приоритет, комментарий менеджера, вложения.
2. **Товары** — каталог популярных позиций, фото, артикулы, наличие, выгрузка Excel/CSV/HTML.
3. **Категории** — группы каталога.
4. **Статьи** — полезные материалы.
5. **Настройки сайта** — контакты, тексты, логотип, favicon, OpenGraph, SEO-описание.

## Безопасность

- формы защищены CSRF-токеном;
- телефон проверяется на клиенте и сервере;
- вложения ограничены по типу и размеру;
- админка закрыта авторизацией;
- для публикации нужно указать DEBUG=False, ALLOWED_HOSTS и CSRF_TRUSTED_ORIGINS в `.env`.
