# 🌾 АГРОМАРКЕТ ТОРШЕНКО — дипломный проект

Сайт для подбора и поставки запчастей для сельскохозяйственной техники.  
Проект выполнен в рамках дипломной работы.

---

## 🔧 Технологии

- **Backend:** Python 3.14, Django 6.0
- **База данных:** PostgreSQL
- **Frontend:** HTML5, CSS3, JavaScript (адаптивный дизайн)
- **Дополнительно:** Chart.js (графики в админке), Django-import-export (выгрузка в Excel)

---

## 📁 Структура проекта
agromarket/
├── agromarket/ # Настройки проекта (settings, urls, wsgi)
├── siteapp/ # Основное приложение
│ ├── models.py # Модели БД (товары, заявки, категории, статьи)
│ ├── views.py # Контроллеры
│ ├── admin.py # Админ-панель
│ ├── utils.py # Утилиты (экспорт в Excel/CSV)
│ ├── static/ # CSS, JS, изображения
│ └── templates/ # HTML-шаблоны
├── manage.py
└── requirements.txt

---

## 🚀 Функциональность

- ✅ **Каталог товаров** с фильтрацией, сортировкой и поиском
- ✅ **Карточка товара** с галереей изображений
- ✅ **Форма обратной связи** с загрузкой файлов
- ✅ **Статьи** с рубриками
- ✅ **Адаптивный дизайн** (десктоп + мобильная версия)
- ✅ **Админ-панель** с:
  - Управлением товарами, категориями, статьями, заявками
  - Статистикой (графики по заявкам и товарам)
  - Экспортом в Excel / CSV / HTML
- ✅ **Глобальный поиск** по сайту (товары + статические страницы)

---

## 📊 База данных

Проект использует **PostgreSQL**. Основные модели:

| Модель | Описание |
|--------|----------|
| `Category` | Категории товаров |
| `Product` | Товары (наличие, цена, артикул) |
| `ProductImage` | Галерея товаров |
| `Lead` | Заявки с сайта (статус, приоритет, история изменений) |
| `Article` | Статьи и полезные советы |
| `SiteSettings` | Настройки сайта (контакты, тексты, SEO, фото) |

## 🧪 Запуск проекта локально

```bash
# Клонировать репозиторий
git clone https://github.com/annapetrova15/agromarket-new.git

# Перейти в папку
cd agromarket-new

# Создать виртуальное окружение
python -m venv venv
source venv/bin/activate      # Linux/macOS
venv\Scripts\activate         # Windows

# Установить зависимости
pip install -r requirements.txt

# Применить миграции
python manage.py migrate

# Создать суперпользователя
python manage.py createsuperuser

# Запустить сервер
python manage.py runserver
